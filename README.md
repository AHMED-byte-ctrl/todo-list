# Interactive To-Do List — Ahmed Nadeem

A single-page to-do list app built with plain HTML5, CSS3, and vanilla
JavaScript. No frameworks, no build step, no dependencies.

## What's included

```
ahmed-todo-list/
├── index.html      The app markup
├── style.css        All styling
└── script.js          All app logic
```

## Features

- Add tasks (press Enter or click "Add")
- Mark tasks complete/incomplete with a click
- Delete tasks individually
- Filter by All / Active / Completed
- "Clear completed" to remove all checked tasks at once
- Live counter of items left, plus a progress bar showing completion
- Tasks persist in the browser's `localStorage` — they survive a page refresh
  and stay in sync automatically across multiple tabs of the same browser
- Clean empty states so the list never looks broken with zero tasks
- Fully responsive down to small mobile widths
- Minimal, light, monochrome interface (Inter + JetBrains Mono, a single
  black accent, and a small green for completed tasks) — no purple or blue
  gradients, no unnecessary decoration

## How to run it locally

No build tools or server required.

### Option 1: Just open it
Double-click `index.html` to open it directly in your browser.
